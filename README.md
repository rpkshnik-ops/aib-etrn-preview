# ЭТрН — публичная тестовая версия

Тёмная концепция лендинга услуг ООО «Компания АиБ» по решению проблем с ЭТрН, ЭПЛ, ЭДО, 1С и TMS.

Телефон и email опубликованы. Тестовая форма подключена к FormSubmit; перед контрольной отправкой владелец должен активировать её по письму на `aaa@aib.expert`. Страница закрыта от индексации до утверждения юридических документов и production-архитектуры обработки заявок.
